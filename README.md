# DSQpay - Local Storage Version
Project simulasi ekosistem fintech sekolah berbasis OOP Python.
Menyimpan database di memori lokal menggunakan Array of Objects.

## Cara Menjalankan
1. Buka terminal di folder `dsqpay_local`
2. Jalankan perintah: `python main.py`
